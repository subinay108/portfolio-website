Scrapshift website for GitHub Pages
1. Replace DEVELOPER_NAME, SUPPORT_EMAIL and EFFECTIVE_DATE in index.html and privacy.html.
2. In app-ads.txt, replace pub-0000000000000000 with your AdMob publisher ID
   (AdMob > Settings > Account information > Publisher ID).
3. Create a public GitHub repository named <your-username>.github.io and upload these files to it.
   The site appears at https://<your-username>.github.io/
   app-ads.txt must sit at that root address, so use this user-site repository (not a project repo).
4. Put https://<your-username>.github.io/privacy.html in Play Console as the privacy policy URL,
   and https://<your-username>.github.io as the website in the store listing.
